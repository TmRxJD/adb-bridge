# local-adb-bridge

**This package is superseded twice over.** It became `tracker-bridge`, and that
is now [adb-bridge](https://www.npmjs.com/package/adb-bridge), which serves The
Tower and other games from a single install.

It still works: it enables The Tower on adb-bridge and hands over, so old
instructions keep doing what they did.

```bash
npx adb-bridge thetower
```

Installers: [latest release](https://github.com/TmRxJD/adb-bridge/releases).
